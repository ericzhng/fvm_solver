# Project: Godunov Riemann type solver for the 1D hyperbolic conservation equations based on finite volume

## Coding style:

- add docstring and comments
- follow PEP 8 style format

## Features:

- reconstruction adopts MUSCL method
- has different flux computation methods such as HLLC, ROE
- consistent framework that can be used for solving Euler, Isoentropic gas, advection equations, etc.
